# CT-SMART EDUC PWA

Files:
- index.html — main CT-SMART EDUC website
- manifest.json — PWA installation information
- sw.js — service worker for app-shell caching
- icons/ — 192px and 512px installation icons

Deployment:
1. Upload all files/folders exactly as arranged to the same website folder.
2. Serve the site over HTTPS.
3. Open the site in Chrome/Edge on a phone or computer.
4. Use the browser's Install app / Add to Home screen option.

Note:
- The live lesson uses Jitsi, so internet access is still required for live meetings.
- The PWA makes the app shell installable/offline-capable; it does not make live Jitsi meetings work without internet.
