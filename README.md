# CT-SMART EDUC

CT-SMART EDUC is a Progressive Web App (PWA) for teacher-controlled live lessons.

## GitHub Pages deployment

Upload the **contents of this folder** to the root of a GitHub repository:

- `index.html`
- `manifest.json`
- `sw.js`
- `icons/icon-192.png`
- `icons/icon-512.png`

Then enable **GitHub Pages** from the repository's Pages settings and select the branch/folder containing `index.html`.

The app uses HTTPS when served through GitHub Pages, so PWA installation is supported by compatible browsers.

### Important
The live lesson uses Jitsi and therefore requires an internet connection.

Teacher access code: `EDUC`  
Founder access code: `LUCK`

Do not publish private administrative credentials in a public repository if the controls are intended to provide real security. The current standalone version uses browser-side settings.
